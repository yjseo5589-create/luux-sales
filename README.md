# LUUX 룩스ㅣ영업 관리

https://yjseo5589-create.github.io/luux-sales/

GitHub Pages에서 바로 실행하는 개인 영업관리 웹사이트.

- 대시보드: 진행 현황, 확인할 프로젝트, 최근 연락 5건, 전체 수주·미수주
- 회사별 담당자 연락처 · 접기/펼치기 · 검색
- 담당자별 연락 기록과 이력
- 프로젝트 관리: 대행사·렙사를 영업 접점으로 연결하고 광고주·브랜드는 직접 입력
- 진행 단계: 제안 준비 → 제안 완료 → 협의 중 → 수주 / 미수주 → 집행 중 → 완료
- 별도 결과 입력 없이 단계에서 수주·미수주 관리, 기존 성공·실패 기록 호환
- 담당자와 프로젝트에서 함께 확인하는 연락 이력
- 별도 서버·로그인 없이 이 브라우저의 localStorage에 저장
- 소유자가 공개를 허용한 기본 연락처: 회사 5개 · 담당자 17명
- 새 브라우저에서는 기본 연락처를 자동으로 표시
- 프로젝트와 개인 연락 이력은 브라우저에 저장하고 저장소에 올리지 않음

데이터는 사용하는 브라우저에만 저장됩니다. 다른 기기·브라우저와 자동 동기화되지 않으며 사이트 데이터를 지우면 저장된 연락처와 이력도 삭제됩니다. 공용 기기에서는 사용하지 마세요.

## 개발·배포

Node.js 22 이상.

```sh
npm ci
npm run dev
npm run build
```

`npm run build`가 GitHub Pages용 `docs/`를 갱신합니다. main 브랜치에 올리면 Pages가 자동 배포됩니다.

## 기본 연락처

공개 승인을 받은 17명 연락처는 `src/default-records.json`에서 관리합니다. 회사·담당자 ID를 유지하여 처음 실행할 때 브라우저에 한 번 반영하며, 기존 브라우저의 수정 내용과 이력은 유지합니다. 주소·출처 메모는 공개 기본 데이터에서 제외했습니다.

앱에서 추가하거나 수정한 내용은 브라우저별로 저장되며 다른 브라우저와 자동 동기화되지 않습니다. 모든 브라우저의 기본 연락처를 바꾸려면 기본 데이터 파일을 수정해 다시 배포합니다. 파일 가져오기 기능은 없습니다.

## 대시보드 집계 기준

- 앱에 저장된 프로젝트와 연락 기록만 집계합니다. 첫 화면은 대시보드입니다. 프로젝트의 #projects·#history 주소는 유지하며 거래처는 #customers에서 엽니다.
- 진행 현황은 제안 준비·제안 완료·협의 중 단계별 프로젝트 수입니다.
- 연락 확인 필요는 제안 완료·협의 중에서 프로젝트에 연결된 마지막 연락이 14일 이상 지났거나 지난 연락 기록이 없는 건입니다. 회사의 다른 캠페인 연락을 대신 사용하지 않습니다.
- 수주·미수주 날짜는 저장 시점에 서울 시간 기준으로 자동 기록합니다. 메모 수정은 날짜를 바꾸지 않으며, 집행 중·완료로 이동해도 단계 이력은 유지합니다.
- 수주 현황은 기간 제한 없이 현재 단계로 집계합니다. 수주·집행 중·완료는 수주에, 미수주는 미수주에 프로젝트별 한 번씩 포함합니다.
- 기존 기록의 과거 변경일은 추정하지 않습니다. 전체 수주 현황은 변경일 유무와 관계없이 현재 단계로 계산하며, 앞으로의 단계 변경일은 자동 기록합니다.
- 대시보드는 제목·수치·목록만 표시합니다. 집계/확인 기준은 제목의 도움말에 두고 등록 버튼은 각 관리 페이지에서만 제공합니다.
- 숫자의 연결 목록은 동일한 집계 대상에서 만들며, 이후 기록을 수정하면 목록도 다시 계산합니다.
