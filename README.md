# LUUX 룩스ㅣ영업 관리

https://yjseo5589-create.github.io/luux-sales/

GitHub Pages에서 바로 실행하는 개인 영업관리 웹사이트.

- 회사별 담당자 연락처 · 접기/펼치기 · 검색
- 담당자별 연락 기록과 이력
- 프로젝트 관리: 광고주·대행사·렙사 및 담당자 연결, 진행 단계·결과·후속 업무·업무 기한
- 제안 및 확정 금액, 집행 일정, 담당자와 프로젝트에서 함께 확인하는 연락 이력
- 별도 서버·로그인 없이 이 브라우저의 localStorage에 저장
- 소유자가 공개를 허용한 기본 연락처: 회사 5개 · 담당자 17명
- 새 브라우저에서는 기본 연락처를 자동으로 표시
- 프로젝트와 개인 연락 이력은 브라우저에 저장하고 저장소에 올리지 않음

데이터는 사용하는 브라우저에만 저장됩니다. 다른 기기·브라우저와 자동 동기화되지 않으며 사이트 데이터를 지우면 저장된 연락처와 이력도 삭제됩니다. 공용 기기에서는 사용하지 마세요.

## 개발·배포

Node.js 22 이상.

```sh
npm ci
npm run dev
npm run build
```

`npm run build`가 GitHub Pages용 `docs/`를 갱신합니다. main 브랜치에 올리면 Pages가 자동 배포됩니다.

## 기본 연락처

공개 승인을 받은 17명 연락처는 `src/default-records.json`에서 관리합니다. 회사·담당자 ID를 유지하여 처음 실행할 때 브라우저에 한 번 반영하며, 기존 브라우저의 수정 내용과 이력은 유지합니다. 주소·출처 메모는 공개 기본 데이터에서 제외했습니다.

앱에서 추가하거나 수정한 내용은 브라우저별로 저장되며 다른 브라우저와 자동 동기화되지 않습니다. 모든 브라우저의 기본 연락처를 바꾸려면 기본 데이터 파일을 수정해 다시 배포합니다. 파일 가져오기 기능은 없습니다.
