# LUUX 룩스ㅣ영업 관리

https://yjseo5589-create.github.io/luux-sales/

GitHub Pages에서 바로 실행하는 개인 영업관리 웹사이트.

- 회사별 담당자 연락처 · 접기/펼치기 · 검색
- 담당자별 연락 기록과 이력
- 별도 서버·로그인 없이 이 브라우저의 localStorage에 저장
- 실제 연락처·이력은 소스와 공개 저장소에 포함하지 않음

데이터는 사용하는 브라우저에만 저장됩니다. 다른 기기·브라우저와 자동 동기화되지 않으며 사이트 데이터를 지우면 저장된 연락처와 이력도 삭제됩니다. 공용 기기에서는 사용하지 마세요.

## 개발·배포

Node.js 22 이상.

```sh
npm ci
npm run dev
npm run build
```

`npm run build`가 GitHub Pages용 `docs/`를 갱신합니다. main 브랜치에 올리면 Pages가 자동 배포됩니다.

## 기존 데이터 이전

`#migration` 화면에서 비공개 이전 파일을 가져옵니다. 대상 브라우저에 기존 데이터가 있으면 덮어쓰기를 중단합니다. 기존 회사·담당자 ID를 유지해 연락 이력을 연결합니다. 이전 파일은 저장소에 올리지 않습니다.
